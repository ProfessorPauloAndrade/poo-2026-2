# Encontro 4 — Projeto 1: CRUD procedural em memória

Neste encontro, o menu passa a guardar até cinco produtos durante a execução do programa. O projeto usa arrays paralelos, busca linear e métodos estáticos para cadastrar, consultar, alterar, remover e listar.

## Para começar

1. Leia o [material do aluno](MATERIAL_ALUNO.md).
2. Consulte a [apresentação](APRESENTACAO.md) ou o [deck no Gamma](https://gamma.app/docs/i4qgseeq50ks4q6).
3. Baixe ou copie o arquivo inicial em [exemplos/encontro-4/aluno/CadastroProdutosInicial.java](exemplos/encontro-4/aluno/CadastroProdutosInicial.java).
4. Implemente e teste as operações uma por vez.

A solução completa permanece fora deste repositório para que a prática seja autoral.
