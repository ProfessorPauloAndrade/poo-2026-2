# Encontro 08 — Coleções e CRUD com ArrayList

Material para o aluno escrever a implementação completa do Projeto 2. Sem soluções ou código parcial fornecido.

- [Enunciado, partes a preencher, regras e testes em branco](MATERIAL_ALUNO.md)
- [Roteiro de estudo e perguntas para preencher](APRESENTACAO.md)

O arquivo Java contém somente comentários: escreva os imports, classes, atributos, construtores, métodos e main. Ele não é um programa executável antes desse preenchimento. Compile e execute após implementar.

A apresentação com demonstrações e a solução ficam no material do professor. Use o JDK adotado pela turma, editor e terminal. Dados em memória; entradas numéricas válidas, com ponto nos preços.
