## Executar

Na pasta do arquivo inicial, com JDK instalado:

```text
javac -encoding UTF-8 ProjetoPedidoListaInicial.java
java ProjetoPedidoListaInicial
```

O esqueleto compila, mas as funcionalidades dependem da conclusão dos TODOs. Compile em uma pasta separada das versões anteriores, que usam classes com os mesmos nomes. Informe números válidos, com ponto nos preços. Dados somente em memória. Sem Internet, use este roteiro e os arquivos baixados; registre commit local no repositório próprio do Projeto 2.

Documentação de consulta: [ArrayList](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/ArrayList.html) e [List](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/List.html).
