Neste estudo preparatório, compare a organização de um cadastro de carros e motos antes e depois de uma refatoração. Construa sua implementação a partir dos requisitos e preserve as duas versões para testar o comportamento.

- [Perguntas de investigação](ROTEIRO_ALUNO_ENCONTRO_11.md)

O arquivo Java contém somente comentários. Cabe ao estudante escrever integralmente a implementação. Use o repositório de exercícios nesta preparação; o repositório próprio do Projeto 3 será iniciado no encontro 12.

Recursos: JDK 21 ou posterior, VS Code, terminal e Git. Siga os comandos já usados no curso, adaptando os nomes dos arquivos que você criar. Trabalhe primeiro localmente se houver falha de Internet. Não envie dados pessoais nem credenciais.
